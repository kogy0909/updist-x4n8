# 배포

최신 파일은 [Releases](../../releases/latest)에서 받으세요.

## 처음 설치

1. zip 다운로드 → 압축 해제
2. `upk-autoK` 폴더의 `install.bat` 실행 (최초 1회)
3. `autostart.vbs` 실행

## 업데이트

받은 zip을 풀어 기존 폴더에 덮어씁니다.
아래 것들은 **덮어쓰지 말고 그대로 두세요** — 설정과 작업물입니다.

| 유지할 것 | 내용 |
|-----------|------|
| `config.json` | 계정·설정 |
| `account_stats*.json` | 사용량 기록 |
| `profiles/` | 로그인 정보 |
| `mascots/` | 등록한 이미지 |

덮어쓰기 전에 폴더를 통째로 복사해 두면 안전합니다.
