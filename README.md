# 배포

최신 파일은 [Releases](../../releases/latest)에서 받으세요.

## 처음 설치

1. zip 다운로드 → 압축 해제
2. `upk-autoK` 폴더의 `install.bat` 실행 (최초 1회)
3. `autostart.vbs` 실행

## 업데이트

**기존 폴더를 지우지 말고, 그 위에 덮어쓰세요.**

zip에는 프로그램 파일만 들어 있습니다.
설정(`config.json`)·로그인(`profiles/`)·사용량 기록은 zip에 없으므로
덮어쓰기만 하면 그대로 유지됩니다.

폴더를 통째로 새로 교체하면 그것들이 사라집니다.
